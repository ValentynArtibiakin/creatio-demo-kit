# Creatio Demo Kit — walkthrough carousel

Плагін для Claude Code: з демо-сценарію він робить **клікабельну карусель екранів Creatio**. Один екран на кожен крок демо, у вигляді Freedom UI, з логотипом клієнта і даними зі сценарію. Результат — одне посилання.

**Навіщо:**
- **Обговорити сценарій до білду.** SC (solution consultant) і консультант бачать, як виглядатиме кожен крок, а не уявляють його з тексту. Зайве видно одразу, нове погоджується на екранах.
- **Обговорити відкриті питання.** На екранах, де сценарій щось лишає відкритим, є блок «Open questions for the SC», а в шапці лічильник, який переводить від питання до питання.
- **Коментувати прямо на екранах.** Кнопка «💬 Comment»: клікаєш поле, рядок або питання і пишеш коментар саме до нього. Коментувати може кожен, кому карусель розшарено з правом коментувати. Потім Claude читає коментарі й вносить правки в карусель.
- **Передати консультантам.** Коли сценарій погоджено і питань не лишилось, та сама карусель стає путівником по демо.
  - Над кожним екраном кроки: хто діє, **Do** (що робимо), **What happens** (що бачимо). Окремо **Say** (що сказати), **Attention** (застереження) і **Issue** (відома проблема).
  - Зверху кнопки use case, згруповані за областями, щоб одразу перейти до потрібного сценарію.
- **Бачити прогалини.** Відомі проблеми позначені на екранах червоним BLOCKER або жовтим GAP, а кнопка «Gaps & blockers: N» проводить по всіх таких екранах.
- **Відповідати на місці.** SC клікає на відкрите питання, Issue кроку або плашку GAP / BLOCKER і пише чи диктує відповідь. Його Claude одразу вирішує, чи питання закрите: якщо так, виправляє екран і кроки під відповідь і прибирає пункт для всіх; якщо ні, лишає його з відповіддю та уточненням.
- **Правити прямо в каруселі.** З доступом Contributor (Can interact) можна:
  - змінити екран через «Change with Claude», текстом або голосом (EN / UA). Зміна одразу зберігається для всіх;
  - повернути попередню версію: Undo або список Versions;
  - поправити текст кроків вручну через «Edit step text».

  Усе, що приходить з бази або від Claude, проходить через очищення HTML: скрипти, обробники подій, `javascript:`-посилання, iframe і зовнішні URL у стилях вирізаються.

Мітки на екранах показують, що з'явиться і як:
- **OOTB** — стандартне Creatio;
- **Config** — налаштування без коду;
- **New** — новий об'єкт або процес;
- **Custom** — поза no-code;
- **Demo mock** — заглушка лише для демо.

Мітки можна сховати перемикачем.

## Встановлення
Потрібно: Claude Code, Python 3 у PATH і доступ до артефактів claude.ai (публікація, база артефакту, коментарі).

```bash
claude plugin marketplace add ValentynArtibiakin/creatio-demo-kit
```
```bash
claude plugin install creatio-demo-kit@artibiakin-demo-kit
```
Після цього перезапусти Claude Code.

**Оновлення:**
```bash
claude plugin marketplace update artibiakin-demo-kit
```
```bash
claude plugin update creatio-demo-kit@artibiakin-demo-kit
```

## Як зробити карусель
У новому чаті Claude Code:
```
Зроби walkthrough-карусель за сценарієм "<повний шлях до сценарію .docx>"
```
1. Claude читає сценарій і показує **список екранів** по юзкейсах. Тут найдешевше щось зрізати чи об'єднати: дай ок або правки.
2. Генерує екрани в стилі Creatio скриптом на `gen_lib` (або, якщо хочеш, малює в дизайн-канвасі). Якщо є стенд зі схожою конфігурацією, може спершу подивитись його **тільки на читання**, щоб екрани були як на стенді. Ти дивишся і правиш.
3. Збирає екрани в одну карусель, перевіряє посилання між ними і проганяє мок-тест редагування, зокрема атаки через HTML.
4. Публікує як Artifact, заливає екрани в базу артефакту і віддає посилання. Ділишся ним через Share: за замовчуванням з усією організацією claude.ai з правом Contributor (Can interact), щоб усі колеги могли відкрити, коментувати й правити.

Після дзвінка з SC передай відповіді: «по черзі L1: одна на всі сайти», «на екрані X прибери Y». Claude оновить екрани, прибере закриті питання і перепублікує карусель за тим самим посиланням. Коли питань 0, це версія для консультантів.

## Дані лишаються в тебе
У репозиторії лише інструкція для Claude, скрипт збірки й оболонка каруселі. Сценарії, екрани й карусель лежать у теці твого демо на ПК, а на GitHub не потрапляють.

## Фідбек
Через [Issues](https://github.com/ValentynArtibiakin/creatio-demo-kit/issues/new/choose), шаблон **Carousel feedback**: на якому кроці і що пішло не так, що хочеш бачити в каруселі.

⚠️ **Репозиторій публічний.** В issues не пиши назв клієнтів, імен людей, адрес стендів і паролів. Посилання на карусель з даними клієнта теж не кидай. Замість назви вказуй галузь і тип демо, наприклад «банк, кредитування, 4 UC».

## Що всередині
```
.claude-plugin/                   plugin.json + marketplace.json
skills/demo-walkthrough-carousel/
  SKILL.md                        інструкція для Claude: сценарій → екрани → карусель
  make_carousel.py                збирає екрани в одну карусель, перевіряє посилання, готує сід для бази
  shell.html                      оболонка: кроки, use case, gaps, коментарі, редагування з очищенням HTML
  DESIGN-NOTES.md                 як виглядає Freedom UI: рамка, меню, рейка іконок, DCM, KPI, Creatio.ai
  tools/gen_lib.py                генератор екранів Freedom UI (автор — Philip Shatunov)
  tools/mock_*.{py,js}            мок-тест редагування перед публікацією
  reference/                      capabilities, інструкції з редагування, прохід по стенду
```
