# Creatio Demo Kit

Плагін для Claude Code з двома інструментами, щоб перевірити сценарій демо **до** того, як його будувати.

| | Що робить |
|---|---|
| **Скіл `demo-walkthrough-carousel`** | Зі сценарію робить клікабельну карусель екранів у стилі Creatio Freedom UI: лого клієнта, дані зі сценарію, мітки OOTB / Config / New / Custom / Demo mock. Одне посилання на Artifact, щоб погодити обсяг із SE. |
| **Агент `demo-effort-estimator`** | Рахує, скільки робочих і календарних днів піде на білд і здачу. Показує, куди йде час, які є ризики і що зрізати під дедлайн. Після кожного зданого демо навчається на твоїх цифрах. |

## Дані лишаються в тебе
У репозиторії лише інструкції для агента і скіла, скрипти та стартові ціни моделі. Тут немає сценаріїв, екранів, назв клієнтів чи історії демо.
- Твої оцінки, журнал зданих демо і правки моделі живуть локально, у `~/.claude/demo-effort/`.
- Екрани й карусель лежать у теці твого демо.

Нічого з цього не потрапляє на GitHub, поки ти сам не створиш issue.

## Встановлення
Потрібно: Claude Code і Python 3 у PATH.

```bash
claude plugin marketplace add ValentynArtibiakin/creatio-demo-kit
```
```bash
claude plugin install creatio-demo-kit@artibiakin-demo-kit
```
Після цього перезапусти Claude Code.

## Оновлення
```bash
claude plugin marketplace update artibiakin-demo-kit
```
```bash
claude plugin update creatio-demo-kit@artibiakin-demo-kit
```
Після оновлення теж перезапусти Claude Code. Твої локальні дані оновлення не перезаписує. Якщо змінились стартові ціни, агент сам запропонує їх злити.

## Як перевірити сценарій
**Карусель:**
```
Зроби walkthrough-карусель за сценарієм "<повний шлях до сценарію .docx>"
```
Claude спершу покаже список екранів по юзкейсах і дочекається твого ок. Потім намалює екрани в дизайн-канвасі, збере їх в одну сторінку і дасть посилання.

**Оцінка днів:**
```
Запусти агента demo-effort-estimator: estimate "<повний шлях до сценарію>"
```
- Після здачі демо: `record <назва демо>`.
- Якщо оцінка або ціна неправильна: `learn <що не так>`.

## Фідбек
Усе через [Issues](https://github.com/ValentynArtibiakin/creatio-demo-kit/issues/new/choose). Є три шаблони:
- **Carousel feedback**: що пішло не так із каруселлю і на якому кроці.
- **Estimate vs fact**: оцінка проти реальності по зданому демо. Агент сам пропонує чернетку після `record`.
- **Model correction**: ціна чи ризик у моделі неправильні для всіх.

⚠️ **Репозиторій публічний.** В issues не пиши назв клієнтів, імен людей, номерів кейсів, адрес стендів і паролів. Замість назви вказуй галузь і тип демо, наприклад «банк, кредитування, 4 UC».

## Що всередині
```
.claude-plugin/          plugin.json + marketplace.json
agents/                  demo-effort-estimator.md
skills/demo-walkthrough-carousel/
  SKILL.md               інструкція для Claude
  make_carousel.py       збирає екрани в одну карусель
  shell.html             оболонка каруселі
data/demo-effort-seed/   стартова модель: ціни й ризики (catalogue.json), правила підрахунку (RUBRIC.md), скрипти; журнал порожній
```

Стартові ціни відкалібровані на внутрішній історії одного білдера: медіанна похибка ~18%. Поки ти не запишеш 2–3 своїх демо через `record`, сприймай оцінки як орієнтир.

Зміни версій описані в [CHANGELOG.md](CHANGELOG.md).
